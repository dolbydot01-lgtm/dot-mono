# 科普视频分镜：保加利亚分腿蹲 —— 从动作到肌节

> 可播放版本：应用顶栏「科普视频」，或直接打开 `/#video`；`/?t=45#video` 可从 0:45 开始。
> 旁白与时间轴的唯一来源是 `src/video/timeline.ts`，本文是对应的设计说明。

## 1. 目标与受众

- **受众**：健身爱好者、体育/康复专业入门学生。
- **目标**：用一次保加利亚分腿蹲，把"动作 → 骨骼杠杆 → 肌肉伸缩 → 肌纤维 → 肌细胞内部（肌节、横桥）"串成一条因果链，让观众理解"我蹲下时，分子层面在发生什么"。
- **时长**：2 分 00 秒，16:9，中英双语字幕。

## 2. 视觉与叙事原则

| 原则 | 做法 |
|---|---|
| 一个时钟贯穿全片 | 所有章节共用同一个"动作时钟"（每次动作 5 秒：顶部 0.6 s → 离心 2.0 s → 底部 0.5 s → 向心 1.3 s → 顶部 0.6 s）。进入微观后，右上角的小窗继续播放动作，肌节长度、横桥方向都与之同步。 |
| 侧视、平面化 | 矢状面二维动画，便于画力线和力臂；深色背景、亮色强调。 |
| 颜色语义固定 | 离心 = 蓝，向心 = 橙，底部 = 紫；肌动蛋白 = 蓝，肌球蛋白 = 橙；钙 = 黄；结缔组织 = 米白。 |
| 层层推进 | 每一级都用"放大镜 / 推镜"转场进入下一级，避免跳切造成的尺度断裂。 |
| 数据说话但不夸大 | 力、力矩、长度为简化模型估算，画面脚注明确标注"示意"。 |

## 4. 分镜细节

### 片头（0:00–0:05）
- **画面**：深色渐变背景；右侧半透明人物开始第一次下蹲；左侧"运动科学 · 科普"→ 标题"保加利亚分腿蹲"→ 副标题；五个胶囊标签"动作 → 骨骼杠杆 → 肌肉 → 肌纤维 → 肌节 · 横桥"依次弹出。
- **旁白**：保加利亚分腿蹲：一次下蹲，从动作一路放大到分子。

### ① 动作（0:05–0:20）
- **画面**：人物侧视，后脚背搭在 45 cm 凳上；髋部轨迹虚线（几乎垂直）；膝（橙）、髋（绿）角度弧在 0:10 后出现。
- **左上**：阶段徽标（离心/底部/向心/顶部 + 进度条）。
- **右侧面板**：膝屈曲 / 髋屈曲 / 踝背屈实时数值（底部约 110° / 98° / 28°）；5 秒节奏条与播放头。
- **标注**：后脚背搭在凳上；前腿承担约 85% 负荷；髋部轨迹几乎垂直下降。
- **旁白**
  1. 后脚搭在约膝高的凳子上，前脚向前一大步，大部分负荷落在前腿。
  2. 下降（离心）约 2 秒：前侧髋、膝弯曲，踝关节背屈，躯干微微前倾。
  3. 起身（向心）：前脚踩实地面，伸髋、伸膝，把身体推回顶部。

### ② 骨骼与杠杆（0:20–0:40）
- **画面**：0–3 s 皮肤淡出、骨骼淡入，髋/膝/踝关节高亮圈；5 s 起出现地面反作用力箭头（蓝）与作用线，膝、髋到作用线的水平虚线标注力臂 d（底部约 14 cm / 28 cm），关节处力矩弧的粗细随力矩变化。
- **右侧面板**：M = F × d；F ≈ 750 N；膝/髋力矩实时数值（底部约 106 / 213 N·m，到达底部时行高亮）；16 s 起出现"股四头肌需要的拉力 ≈ 3.4 × 体重"及髌腱力臂说明。
- **旁白**
  1. 去掉皮肤和肌肉，身体就是一套杠杆：骨骼是杠杆，关节是支点。
  2. 地面反作用力从前脚向上。它到膝、髋的垂直距离就是力臂——力臂越长，关节需要的肌肉力矩越大。
  3. 到了底部，膝盖前移、髋部后移，两个力臂同时达到最大：这是全程最吃力的位置。
  4. 肌肉附着点离关节很近，力臂只有几厘米，所以股四头肌要产生数倍于体重的拉力。

### ③ 肌肉伸缩（0:40–1:00）
- **画面**：腿部放大；骨骼半透明；肌肉以梭形肌腹绘制于起止点之间（股四头肌经髌骨、髌腱到胫骨粗隆）。颜色亮度 = 估算激活；肌腹宽度随拉长变细。
- **聚焦节奏**：0–11 s 主动肌（股四头肌、臀大肌、大收肌）；11–16 s 加入腘绳肌、股直肌；16–20 s 臀中肌与后腿股直肌。
- **左侧状态句**：离心"一边被拉长，一边发力'刹车'"/ 向心"主动缩短，把身体推起"/ 底部"等长发力，换向的瞬间"。
- **右侧面板**：8 块肌肉的角色标签、长度变化条（以站立为 0，蓝 = 变长、橙 = 变短）、激活条。底部参考值：股四头肌 +16%、臀大肌 +18%、大收肌 +32%、腘绳肌 +7%、股直肌 −5%、后腿股直肌 +6%。
- **旁白**
  1. 股四头肌伸膝，臀大肌和大收肌伸髋——它们是这个动作的主动肌。
  2. 下降时它们一边用力一边被拉长，这叫离心收缩，像刹车一样控制下落。
  3. 起身时同样的肌肉主动缩短（向心收缩）。腘绳肌同时跨越髋和膝，长度变化很小，主要协同与稳定。
  4. 臀中肌防止骨盆侧倾、膝盖内扣；后腿的股直肌被拉长——上身越直立，拉伸越明显。

### ④ 肌束与肌纤维（1:00–1:20）
- **0–4.4 s**：镜头跟随大腿，股外侧肌高亮，黄色放大镜圈出肌腹并推进。
- **4–9.8 s**：整块肌肉横截面——米白色肌外膜包裹 19 个肌束，每束有肌束膜；标注肌外膜 / 肌束 / 肌束膜。随后推进到一个肌束。
- **9–14.8 s**：肌束内部——数十根肌纤维（六角排列），每根边缘有紫色细胞核、内部有肌原纤维点；标注"肌纤维 = 一个肌细胞"、肌内膜、"多核、贴边"、直径 10–100 µm。
- **14–20 s**：单根肌纤维侧视，明暗横纹；运动神经元末梢在神经肌肉接头释放乙酰胆碱（绿点），黄色动作电位从接头向两侧扩散；放电间隔随激活程度从约 1.1 s 缩短到 0.3 s，并实时显示频率。
- **常驻**：右上角小窗播放动作，显示"股四头肌：拉长中 / 缩短中 / 等长"。
- **旁白**
  1. 把镜头推进前腿的股外侧肌。
  2. 整块肌肉由肌外膜包裹，里面是一束束肌束，每一束外面包着肌束膜。
  3. 每个肌束里有成百上千根肌纤维。一根肌纤维就是一个肌细胞：细长、多核，直径约 10–100 微米。
  4. 运动神经元在神经肌肉接头释放乙酰胆碱，触发动作电位传遍整根纤维。需要更大力量时，神经系统会募集更多运动单位、提高放电频率。

> 说明：需求中的"肌纤维 → 肌细胞"在生理上是同一个对象（一根骨骼肌纤维就是一个多核肌细胞），因此本片在 ④ 中点明这一点，⑤ 则进入细胞内部。

### ⑤ 肌细胞内部：肌节与横桥（1:20–1:50）
- **0–6 s 细胞内部**：剖开的肌纤维，切面可见肌原纤维；纵向 5 根带横纹的肌原纤维之间是青色肌浆网，紫色横小管从细胞膜垂直深入；每次动作电位后黄色 Ca²⁺ 从肌浆网涌出并消散（与 ④ 同一放电模型）。
- **6–10 s 肌节链**：一根肌原纤维上首尾相连的肌节，中央一个以黄框标出"Z 线到 Z 线"。
- **10–18 s 单个肌节（核心画面）**：Z 盘（锯齿）、M 线（虚线）、蓝色细肌丝从 Z 盘伸出、橙色粗肌丝居中带肌球蛋白头、灰色肌联蛋白弹簧。**肌节长度实时跟随股四头肌**：站立约 2.3 µm，底部约 3.0 µm。上方/下方括号标出 A 带（恒定 1.6 µm）、I 带、H 区，右侧面板实时显示四个数值。肌球蛋白头在向心时摆动、离心时后倾。
- **18–30 s 横桥循环特写**：双链肌动蛋白、原肌球蛋白（紫）、肌钙蛋白（黄）+ Ca²⁺；一个放大的肌球蛋白头按 2.4 s 周期循环四步，右下步骤表同步高亮：
  1. Ca²⁺ 结合肌钙蛋白，原肌球蛋白移开，结合位点（绿点）暴露；
  2. 携带 ADP + Pi 的头部结合肌动蛋白；
  3. 释放 Pi、ADP，头部从 60° 摆到 120°（动力冲程），细肌丝被拉向 M 线；
  4. ATP 结合、头部脱离，ATP 水解后重新"上膛"。
  
  **随动作分支**：向心时细肌丝随动力冲程向 M 线移动；离心时细肌丝被持续拉向反方向，头部被向后拖拽后强行脱离，并出现说明条"横桥在完成动力冲程前就被强行拉开：单个横桥承受更大的力，ATP 消耗更少"；顶部/底部为等长，头部只产生张力不滑动。
- **旁白**
  1. 肌细胞里塞满了肌原纤维。动作电位经横小管深入细胞，肌浆网随即释放钙离子。
  2. 肌原纤维由一节节肌节首尾相连，肌节是肌肉收缩的最小单位。
  3. 粗肌丝（肌球蛋白）与细肌丝（肌动蛋白）交错排列。收缩时二者相对滑动：A 带长度不变，I 带和 H 区变窄。
  4. 横桥循环：钙离子让结合位点暴露，肌球蛋白头抓住肌动蛋白、摆动完成动力冲程，再由 ATP 帮它松开并重新"上膛"。
  5. 下蹲时横桥被负荷强行拉开：离心收缩能产生更大的力、耗能更少，但更容易引起延迟性肌肉酸痛。

### ⑥ 总结（1:50–2:00）
- **画面**：五张卡片依次浮现（动作 / 骨骼杠杆 / 肌肉 / 肌纤维 / 肌节 · 横桥），每张配图标与一句话；5 s 后出现训练提示框。
- **旁白**
  1. 一次分腿蹲：关节构成杠杆，肌肉产生力矩，神经驱动肌纤维，亿万个横桥在肌节里拉动细肌丝。
  2. 训练提示：下降控制 2–3 秒，前膝与脚尖方向一致；躯干稍前倾偏重臀部，更直立则偏重股四头肌。

## 5. 科学依据与简化说明

| 项目 | 取值 / 处理 | 说明 |
|---|---|---|
| 人体参数 | 70 kg，大腿、小腿各 0.43 m，躯干 0.5 m | 1.75 m 成年人近似比例 |
| 负荷 | 2 × 10 kg 哑铃，前腿承担 85% | 假设值；实际占比随步幅、凳高和躯干前倾变化 |
| 关节角度 | 底部膝屈 ~110°、髋屈 ~98°、踝背屈 ~28°，躯干前倾 5°→16° | 常见动作范围 |
| 力矩 | 静力学：竖直地面反作用力 × 关节到作用线的水平距离 | 忽略惯性、肢体自重分布与剪切力 |
| 股四头肌力 | 膝力矩 ÷ 髌腱力臂 4.5 cm | 底部约 3.4 倍体重；用于说明"数倍体重"的量级，非精确值 |
| 肌肉长度 | 起止点（含髌骨绕行）之间路径长度 | 二维近似，肌肉实际有三维走向 |
| 激活程度 | 由关节力矩估算，离心期 × 0.8 | 体现力–速度关系，**非实测肌电** |
| 肌节长度 | 2.3 → 3.0 µm 随股四头肌长度线性映射 | 处于人类骨骼肌常见工作范围；粗肌丝 1.6 µm、细肌丝 1.0 µm |
| 放电频率 | 随激活从 ~1 Hz 到 ~3 Hz（示意） | 实际运动单位放电频率更高（约 5–50 Hz），为可视化放慢 |
| 横桥周期 | 2.4 s / 次（示意） | 实际为毫秒级，放慢以便观察 |

## 6. 制作说明

- **实现**：`src/video/` —— `kinematics.ts`（动作与生物力学模型）、`timeline.ts`（章节与旁白）、`scenes/`（7 个场景）、`svg/`（人物、骨骼、肌肉、标注等组件）、`player/`（播放器）。
- **确定性渲染**：每一帧都是时间的纯函数，任意拖动进度都与正常播放一致，也便于今后逐帧导出。
- **导出成片**：目前可用系统录屏（全屏模式 + 1080p）获得 MP4；如需配音，按第 4 节旁白录制，时间点以 `timeline.ts` 中各 `at` 为准。
