## 参考答案

**A1**　四个层次：① 原始层（区块头、交易、收据、logs、trace）；② 解码层（用 ABI 把事件解码成结构化参数）；③ 抽象层（swaps、transfers、borrows 等事实表，tokens、pools、labels 等维度表）；④ 指标层（按日/池/用户聚合的 TVL、volume、fees、retention、HHI）。幂等：同一区块或事件重复投递不能重复计数，否则成交量、费用、留存都会被高估。reorg 回滚：同一高度出现不同区块哈希时，必须删除该高度及以上的旧事件，再应用新块；否则会同时保留已失效的旧交易和新交易。事件主键用 `(txHash, logIndex)`，因为一笔交易可能产生多个同类型事件。

**A2**　重复计算指同一份资本被多个协议同时计入 TVL。机制：① 循环借贷（存入 A → 借出 75% → 存入 B → 再借出）；② LP 凭证再抵押（DEX 已计入 ETH/USDC，农场又把 LP token 计入）；③ 再质押/包装（ETH → stETH → 再质押 → LRT → 再存入借贷）。gross TVL 是各协议锁仓资产的简单加总；net TVL 剔除再存入的 borrowed funds、LP 凭证和其他重复项，更接近独立资本。报告时必须注明口径。

**A3**　fees 是用户支付的总费用；revenue 是协议留存的部分（如协议金库分成）；earnings 是 revenue 再扣除 token 激励与运营成本；token incentives 是协议增发代币支付的补贴，不是真实收入。P/F = FDV / 年化 revenue（或 fees）。早期协议常用高额激励推高 TVL 和成交量，若只看激励前收入会严重高估估值；激励后净收入才接近可持续现金流。两个口径都应披露，并说明激励是否会被回购/销毁抵消。

**A4**　一个用户多个地址：空投农民用 20 个地址领取代币，每个地址都算"活跃"；一个地址多个用户：交易所 omnibus、桥、托管地址背后是成千上万用户，却被算作一个地址。队列留存按"首次使用时间"分组，跟踪同一批地址在后续周/月是否再次出现，能减少整体平均值被新增地址稀释的问题；但仍需地址聚类、机器人过滤和"有意义的活跃"定义（如支付手续费、完成交易、持有非零余额），才能接近真实用户留存。

**A5**　HHI 衡量份额平方和，对大份额敏感；Gini 衡量持有量分布的不平等；Nakamoto 系数衡量控制 1/3、1/2、2/3 所需的最少实体数。原始地址视图会把同一实体的多个地址拆开，降低 HHI/Gini；交易所 omnibus 又把大量用户资产集中到一个地址，可能制造虚假集中。地址聚类的假阳性包括：交易所内部归集、做市商多地址、faucet/空投分发、机器人批量操作、共享热门合约、UTXO CoinJoin。聚类是概率性的，必须报告置信度。

**A6**　事件研究假设"没有事件时，异常收益的期望为 0"，且基准模型能正确刻画正常收益；链上场景中，事件常与行情、协议升级、空投快照同时发生，基准模型可能遗漏混杂因素。DID 假设平行趋势（无处理时两组趋势相同）与 SUTVA（无溢出）；空投可能改变对照组行为（他们也去刷量），或处理组在快照前就提前行动。面板回归假设模型设定正确、误差与处理不相关、标准误按实体/时间聚类；地址聚类错误、协议升级、机器人污染都会破坏这些假设。

**C2 参考**
1. 对账仍会通过，稳健结果仍是 44 条、$551,480；但 `reorgedBlocks` 从 2 变成 1，`rolledBackEvents` 从 5 变成 3。原因：`affected` 集合只负责从 `appliedBlocks` 删除区块并累加回滚计数；真正删除事件行的是另一行 `robustRows.filter(r => r.blockNumber < block.number)`。当新 18 到达时，`affected` 只包含 19（`n > 18`），所以旧 18 没有计入 `reorgedBlocks/rolledBackEvents`；但 `robustRows` 仍会删除所有高度 ≥18 的旧行，因此最终事件集正确。这个练习说明：**最终对账通过，不代表所有监控/审计计数正确**；数据质量检查要同时覆盖结果与过程指标。

**D1 参考**　TVL 可被循环借贷/再质押重复计算；资产价格下跌会让 TVL 自动缩水，即使没有资金流出；TVL 不显示负债端（借款、LP 赎回义务）；高 TVL 不带来收入；TVL 激励吸引的是雇佣资本，留存低。应补充：净 TVL / TVS、协议 revenue 与真实 yield、付费用户留存、TVL 的负债与期限结构。结论：TVL 是"锁仓规模"的描述性指标，不是协议健康度或估值的单一证据；要和收入、留存、风险指标一起看。
