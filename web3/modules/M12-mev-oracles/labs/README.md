## Lab 12.1 三明治攻击：最优前置规模

```bash
node modules/M12-mev-oracles/labs/01-sandwich-optimal.mjs
```

| 文件 | 内容 |
|---|---|
| `01-sandwich-optimal.mjs` | 恒定乘积 AMM 买卖、三明治账本、利润一阶条件四次多项式、扫描+二分求根、网格搜索、受害者规模与池深敏感性 |

实验参数：池子 1,000 ETH / \$2,000,000 USDC（价格 \$2,000），手续费 0.3%，受害者用 \$10,000 买入 ETH。

预期输出（节选，数字应与实际运行一致）：

```
--- 1. 无攻击时的受害者成交 ---
受害者得到 4.960273 ETH，平均成交价 $2,016.02
相对现货价 $2,000.00 的滑点 = 0.801%

--- 2. 最优攻击的完整账本 ---
一阶条件解（有效输入 A） = $538,129.02，实际支付 a = A/(1-φ) = $539,748.27
攻击者买入 212.017994 ETH；受害者只得到 3.083154 ETH
攻击者卖出得到 $540,632.84，毛利润 = $884.57
利润 / 前置资本 = 0.1639%（单次攻击的资本回报率）
受害者滑点损失（按初始价计） = $3,754.24

--- 3. 解析一阶条件 vs 网格搜索 ---
解析 FOC 根: a = $539,748.27，利润 = $884.5718
网格搜索:    a = $540,000.00，利润 = $884.5717（步长 $1,000）
利润差 = $0.0001，前置规模差 = $251.73
```

```
--- 5. 受害者规模与池子深度敏感性 ---
受害者输入($)   最优前置($)     攻击利润($)    利润/受害者
       1,000              0          0.00       0.00%
       5,000              0          0.00       0.00%
       7,000        151,366         68.63       0.98%
      10,000        539,748        884.57       8.85%
      50,000      2,837,353     29,286.76      58.57%
     100,000      4,205,333     72,684.57      72.68%
```

**检查点**

1. 无攻击时受害者得到 4.960273 ETH，平均价 \$2,016.02，滑点 0.801%。
2. 最优前置有效输入 \$538,129.02，实际支付 \$539,748.27；攻击者买入 212.017994 ETH，受害者只得到 3.083154 ETH。
3. 攻击者卖回 \$540,632.84，毛利润 \$884.57；利润/前置资本仅 0.1639%，说明三明治是“高频、低单次回报”的生意。
4. 受害者滑点损失 \$3,754.24，其中 \$884.57 被攻击者拿走，其余主要支付给 LP 手续费。
5. 解析 FOC 根 \$539,748.27 与网格 \$540,000 的利润差只有 \$0.0001，验证了推导和求根。
6. 受害者 \$1,000、\$5,000 时最优前置为 0、利润为 0（无盈利攻击），\$7,000 开始有利可图；池子越深，同样的受害者交易利润越低，10,000 ETH 深度时利润为 0。

## Lab 12.2 TWAP 预言机操纵成本

```bash
node modules/M12-mev-oracles/labs/02-twap-manipulation-cost.mjs
```

| 文件 | 内容 |
|---|---|
| `02-twap-manipulation-cost.mjs` | 单块尖峰、持续 N 块操纵、目标涨幅/流动性敏感性、单块 vs 持续的“单位 TWAP 偏差成本”对比 |

实验参数：池子 10,000 ETH / \$20,000,000 USDC（$P_0=2{,}000$），手续费 0.3%，区块 12 秒；每块套利把价格向 $P_0$ 拉回当前偏差的 50%。

预期输出（节选）：

```
--- 1. 单区块现货操纵：便宜，但 TWAP 几乎不动 ---
TWAP 窗口(块)   目标涨幅   买入花费($)      卖出回收($)      净成本($)      TWAP($)      TWAP 偏差
           30       10%      979,114.31       973,384.33      5,729.98    2,006.67     0.333%

--- 2. 持续操纵：要把 TWAP 维持在目标价，必须每个区块对抗套利 ---
窗口(块)   累计买入($)       累计 ETH      卖出回收($)      净成本($)      期末价格($)
      30    15,007,186.03     6,972.24     8,525,255.82   6,481,930.21        716.24

--- 5. 关键对比：单块尖峰 vs 持续 30 块 ---
单块尖峰: 净成本 $5,729.98，TWAP 偏差 0.333%，每 1% 偏差成本 $17,189.93

持续操纵的“单位 TWAP 偏差”成本约为单块尖峰的 37.7 倍。
```

**检查点**

1. 单块 +10% 的买入花费 \$979,114.31，卖回 \$973,384.33，净成本 \$5,729.98；30 块窗口的 TWAP 只到 \$2,006.67（+0.333%）。
2. 持续 30 块 +10% 需要累计买入 \$15,007,186.03，净成本 \$6,481,930.21，期末价格 \$716.24；成本不是“买一次”，而是每块都要对抗套利。
3. 单块尖峰的“每 1% TWAP 偏差”成本 \$17,189.93；持续 30 块是 \$648,193.02，后者是前者的 37.7 倍。
4. 池子从 10,000 ETH 降到 1,000 ETH，30 块 +10% 净成本从 \$6,481,930.21 降到 \$648,193.02；升到 100,000 ETH 则升到 \$64,819,302.10。成本约与流动性深度成正比。
5. 目标涨幅从 5% 升到 50%，净成本从 \$2.16M 升到 \$50.23M，边际成本随恒定乘积的凸性上升。
6. 持续模型即使 N=1，也要持有到区块末再卖，净成本 \$48,982.35；单块尖峰假设买卖在同一笔交易内完成，净成本 \$5,729.98。两者假设不同，不能直接比较。

**任务**

1. 把每块拉回比例 `BETA` 从 0.5 改成 0.2、0.8，重跑实验。套利越强（β 越大），持续操纵成本如何变化？为什么？
2. 把 30 块窗口改成 120 块，重跑 +10% 情景。成本大致按什么比例增长？TWAP 的防御是否线性？

4. 把 `simulateSustained` 中的 `targetMultiple` 改成 1.25、1.50，记录“每 1% 偏差成本”。为什么价格推得越高，单位偏差成本越高？

## 常见问题

- **为什么最优前置不是“越大越好”？** 前置越大，攻击者自己的买入价越高，卖回时的价格冲击和手续费也越大；存在一个使边际收益等于边际成本的规模。
- **为什么零手续费时没有有限最优？** 利润单调趋近于受害者的输入，攻击者愿意无限前置；手续费、gas 和竞争才让规模有限。
- **为什么 TWAP 的操纵成本与流动性成正比？** 要把价格推高同样的幅度，池子越深，需要的买入量越大；要维持价格，每块对抗套利的量也越大。
- **为什么“攻击者不赚钱”仍可能伤害协议？** 协议按被操纵的价格借款/清算，即使攻击者的交易本身亏损，坏账仍可能由存款人承担；攻击者也可能通过其他头寸获利。
