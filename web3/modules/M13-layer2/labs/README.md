# M13 实验手册

本目录包含两个零依赖、可离线运行的 ESM 实验。所有随机过程使用固定种子的 `mulberry32`，输出可复现；金额使用 `BigInt` 的 wei/gwei 最小单位计算，避免浮点误差。

## 环境与运行方式

要求：Node.js 18+（建议 20+），在仓库根目录执行。无需安装新依赖，无需联网。

```bash
cd /Users/dolbydot/dot-mono/web3

node modules/M13-layer2/labs/01-fee-split.mjs
node modules/M13-layer2/labs/02-op-vs-zk.mjs
```

两个脚本都只使用 Node 内置能力，不读取网络或环境变量。运行时间均在 1 秒内。

### 这个实验在算什么

1. **批次费用**：`压缩后字节数 = 笔数 × 原始字节 / 压缩比`；`blob 数 = ceil(批次字节 / 126,976)`；`blob 成本 = blob 数 × 131,072 × blob base fee`。注意 blob base fee 的单位是 wei/blob gas。
2. **L2 收入**：`用户费用 − (blob 成本 + 提交 gas 成本)`。执行成本只影响利润，不影响课程定义的"收入"。
3. **敏感性**：blob fee 从 1 wei 涨到 1e11 wei，数据成本跨越 11 个数量级；盈亏平衡点约 4.0944e10 wei/blob gas。
4. **挑战期资本成本**：`提款额 × 年化机会成本 × 天数/365`。快速桥费率低于这个值时，用户理性上应等待；高于时，快速桥有市场。
5. **Little's law**：稳定状态下，系统中平均锁定资金 `L = λW`（到达率 × 平均停留时间）。模拟值与解析解的相对误差约 0.19%，验证了模型。

### 这个实验在算什么

1. **时间轴**：L1 最终性按 2 个 epoch（约 12.8 分钟）；OP 提款 = L2 包含 + 批次上 L1 + 7 天挑战期 + L1 最终性；ZK 提款 = L2 包含 + 证明生成 + L1 验证/最终性 + 桥接缓冲。
2. **成本模型**：ZK 每批有固定证明成本（生成 + 验证），批次越大每笔越便宜；OP 的成本主要是保证金摊销与每笔监控成本，几乎不随批次大小变化。
3. **递归聚合**：把 8 个批次证明聚合成 1 个，验证 gas 分摊到 8 批，盈亏平衡批次从 73,434 降到 10,684。
4. **信任模型**：OP 需要至少一个诚实观察者；如果每个观察者独立离线概率 5%，5 个观察者全部离线的概率是 `0.05^5 = 3.125e-7`。ZK 的可靠性来自证明系统，但仍需信任实现与电路。
5. **证明时间分布**：对数正态适合描述"大多数证明很快、少数很慢"的长尾；解析解与模拟值的误差在 1% 以内。长尾意味着 p99 可能远高于中位数，桥的流动性规划要按 p99 而非均值准备。

## 常见问题

**Q：为什么 blob 成本显示成 `$4.719e-9`？**
A：因为示例中 blob base fee 只有 12 wei/blob gas，1 个 blob 的成本是 1,572,864 wei，即 1.573e-12 ETH；按 $3,000 换算只有 4.7e-9 美元。脚本对小额使用科学计数法，避免显示成 0。

**Q：为什么 L2 收入不是用户费用全额？**
A：课程把"收入"定义为扣除 L1 数据成本后的净额；执行、证明、运营等再计入利润。真实项目财报口径可能不同，读数据时要先确认定义。

**Q：为什么 OP 的 7 天挑战期在时间轴里是 604,800 秒？**
A：`7 × 86,400 = 604,800`。加上 L2 包含、批次上 L1 与 L1 最终性，总时间约 605,870 秒，即 7.01 天。

**Q：这些数字是当前主网数据吗？**
A：不是。它们是教学参数，用于展示数量级与敏感性。主网 blob 费用、gas 价格、证明成本与 L2 参数会随时间变化；引用时请标注日期与来源。
