## Lab 9.1：恒定乘积 AMM 的全景

### 模型

- 初始池：100 ETH + 200,000 USDC，$k=20{,}000{,}000$，现货价 \$2,000，手续费 0.3%；
- 用 0.1、1、5、10、50、100 ETH 换 USDC，比较输出、执行价、曲线冲击、含费滑点与 $k$；
- 拆单实验：10 ETH 拆成 1、10、100、1,000、10,000 笔，比较有费/无费输出；
- LP 实验：Alice 存入 10 ETH + 20,000 USDC（10% 份额），在一笔 10 ETH 交易后计算价值与 HODL 的差；
- IL 表：$r=0.25$ 到 9；
- v3：$L=100$，四个区间，比较同等 $L$ 所需资本与资本效率；
- StableSwap：1M/1M 池，100,000 USDC 换 USDT，$A=100$，手续费 0.04%，与 CP、恒定和对比。

### 关键输出

```text

...

...
单笔含费输出 18,132.22 USDC；无费输出 18,181.82 USDC。
```

```text
Alice 的 10,000 / 100,000 LP 份额可赎回：11.0000 ETH + 18,186.78 USDC
按新价格计值：36,373.56；若她一直持有 10 ETH + 20,000 USDC：36,533.43
差额：-159.88（-0.438%），其中她分到的手续费约 $4.96。
```

```text

[1500, 3000]       0.410326     599.1526    1,419.80     8,944.27        6.3x
[1800, 2200]       0.104061     229.4953      437.62     8,944.27       20.4x

```

```text
CP（x·y=k）输出：90,876.03 USDT，执行价 0.9088
StableSwap（A=100）输出：99,909.82 USDT，执行价 0.9991
恒定和（理想 1:1）输出：99,960.00 USDT，执行价 0.9996
手续费 0.04% 后，StableSwap 的滑点约 -0.090%；CP 的滑点约 -9.124%。
```

### 观察与结论

1. **价格冲击随交易规模非线性上升**：10 ETH（池子的 10%）把价格从 2,000 推到 1,653，执行价 1,813；100 ETH 的执行价只有 998.50，滑点 -50%。AMM 的“深度”是相对的：交易越大，池子越薄。
2. **手续费让 $k$ 增长**：10 ETH 交易后 $k$ 从 20,000,000 增到 20,005,456；这是 LP 的收入来源，但远不足以覆盖这笔大交易造成的 IL。
3. **拆单不总是更好**：无手续费时路径无关，输出都是 18,181.82；有手续费时拆得越碎，输出略低（18,130.07 vs 18,132.22）。拆单降低价格冲击，但每笔都付手续费；路由要在两者之间权衡。
4. **IL 与路径无关**：$r=4$ 与 $r=0.25$ 都是 -20%；LP 在涨跌两侧都跑输 HODL。
5. **v3 用区间换资本效率**：同样 $L=100$，[1500,3000] 只需 \$1,419.80，[1998,2002] 只需 \$4.47，资本效率 2,000×；但窄区间极易越界，越界后停止赚费。
6. **StableSwap 在锚定附近几乎 1:1**：100,000 USDC 换 USDT，CP 输出 90,876，StableSwap 输出 99,910，滑点从 -9.12% 降到 -0.09%。$A$ 越大越接近恒定和，但极端脱锚时保护越弱。

### 实验任务

1. 把 `PHI` 改为 `0.0005`（5 bp），重跑第 1 节：10 ETH 交易的 LP 手续费收入变成多少？与 IL 相比如何？
2. 在 `swapState` 中加入 `minDy` 检查：如果输出低于用户下限就抛错；用 10 ETH、`minDy=18,000` 与 `minDy=18,200` 各试一次。
3. 把 v3 区间改为 `[1900,2100]` 与 `[1999,2001]`，计算资本效率；解释为什么区间越窄，越界风险越高。
4. 用 Balancer 加权不变量实现 80/20 池，复现 README 中 100 BAL → 96.95 WETH 的结果；再算 50/50 同价值池的输出。
5. 把 StableSwap 的 $A$ 改为 1、10、1000，记录输出与滑点；画出 $A$ 与滑点的关系（表格即可）。
6. 给 LP 头寸加入“手续费累计”：让 Alice 在多笔交易后赎回，比较“手续费收入 − IL”与 HODL；手续费率多高才能覆盖这笔 10 ETH 交易的 IL？

### 常见问题

- **为什么 10 ETH 交易的曲线冲击是 -9.066%，含费滑点是 -9.339%？** 曲线冲击只反映 $x$ 变化对价格的影响；含费滑点还把 0.3% 手续费算进去。两者相差约 0.27 个百分点。
- **为什么 Alice 的 LP 价值比 HODL 少 \$159.88，但只分到 \$4.96 手续费？** 这笔交易太大（池子的 10%），价格冲击主导；手续费按 0.3% 收取，摊到 10% 份额只有约 \$4.96。IL 是相对 HODL 的机会成本，不是“已实现亏损”。
- **为什么 v3 的 [1998,2002] 资本效率是 2000.5×，而公式给 2000×？** 区间边界与当前价格的相对位置导致精确值略高于近似；2000.5 是脚本用实际 $x,y$ 算的，公式在窄区间近似为 2000×。
- **为什么 StableSwap 的输出不是 99,960？** 99,960 是“恒定和”理想值（仅扣 0.04% 手续费）；StableSwap 仍有一点点曲线惩罚，所以是 99,909.82，滑点 -0.090%。

## Lab 9.2：无常损失与 LVR

### 模型

- ETH 价格服从 GBM（$\mu=0$），365 个日步长；
- 池子 250 ETH + 500,000 USDC，$P_0=2{,}000$，$V_0=\$1M$，$k=125{,}000{,}000$；
- 每步价格变动后，套利者把池价交易到外部价，套利利润 = LP 相对“持续再平衡/Delta 对冲组合”的损失（LVR）；
- 解析 LVR：$\ell=\sigma^2V/8$，一年 $\text{LVR}=\sigma^2V_0/8$；
- IL：$\text{IL}(r)=2\sqrt r/(1+r)-1$，$r=P_T/P_0$；
- 单条路径（种子 42）、5,000 条路径（$\sigma=60\%$）、波动率网格（0.2–1.0）、盈亏平衡换手率。

### 关键输出

```text
期末：LP 1,246,579.49，HODL 1,276,980.21，LVR 44,387.13，
IL（模拟）= -2.38%，IL（公式）= -2.38%，误差 4.44e-16。
```

```text
LVR 均值 43,691.47，中位数 42,610.75，标准差 8,349.73，标准误 118.08
解析值 σ²/8·V0 = 45,000.00；相对误差 -2.91%
...
IL 均值 -4.55%，中位数 -2.36%，P5 -16.88%，P95 -0.02%
```

```text

0.2    5,000.00    4,990.32     -0.19%     -0.51%          3.00%     2.50%
```

```text

1.0       250.0x        41.7x        12.5x
```

### 观察与结论

1. **IL 公式精确**：逐路径模拟与 $\text{IL}(r)$ 的最大误差约 $10^{-15}$，说明端点 IL 只取决于价格比，与路径无关。
2. **LVR 与 IL 是不同基准**：单条路径期末 IL 为 -2.38%，累计 LVR 为 \$44,387；两者不必相等，因为 IL 对比静态 HODL，LVR 对比持续再平衡组合。
3. **蒙特卡洛均值接近解析值**：$\sigma=60\%$ 时模拟 LVR 均值 \$43,691，解析值 \$45,000，相对误差 -2.91%；误差来自日步长离散化与 $\sigma$ 的高阶项。
4. **低波动收敛更好**：$\sigma=20\%$ 误差 -0.19%，$\sigma=100\%$ 误差 -5.49%；波动率越高，离散化误差越大。
5. **手续费必须覆盖 LVR**：$\sigma=60\%$、费率 0.3% 时，年换手需要 15 倍才能打平；10 倍周转只有 3% 手续费，而 LVR 约 4.5%，净收益约 -1.5%。
6. **波动率翻倍，LVR 变 4 倍**：因为 LVR 与 $\sigma^2$ 成正比；$\sigma=100\%$ 时解析 LVR 是 \$125,000，占池子 12.5%。

### 常见问题

- **为什么单条路径的 LVR 是 \$44,387，而解析值是 \$45,000？** 单条路径的随机波动很大；解析值是期望值，不能拿来判断一条路径“对不对”。要看 5,000 条路径的均值。
- **为什么模拟均值比解析值低 2.91%？** GBM 的日步长离散化、对数正态的高阶项、以及“每步套利到外部价”的离散假设；步长越小，越接近连续时间解析值。
- **为什么 IL 均值是 -4.55%，而中位数是 -2.36%？** IL 对价格变动是非线性的，分布右偏/左偏；均值被大幅波动的路径拉低。报告分布时不能只看均值。
- **IL 与 LVR 可以相加吗？** 不可以。它们基准不同：IL 是相对静态 HODL 的端点差，LVR 是相对再平衡组合的流量损失。把两者相加会重复计算/混淆概念。
