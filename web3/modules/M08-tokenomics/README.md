## 1. 直觉：代币是“协调工具”，不是“股票”

假设你要启动一个双边市场：一边是交易者，一边是做市商。冷启动时两边都不来。你可以：

- 收交易费补贴做市商——但早期没有收入；
- 发股权融资——流程长、门槛高；
- 发**代币**：把未来的使用权、治理权和潜在现金流打包成一种可流通凭证，先发给早期参与者，换取他们现在就来。

代币的经济学本质是**用可编程的产权换取早期协调**。它可以是补贴、会员卡、投票权、质押凭证，也可以是证券——取决于它承诺了什么、如何分配收入、由谁治理。

> 关键区分：**代币价格 ≠ 协议价值**。价格是供需与叙事的产物；价值捕获取决于代币持有人对协议现金流、治理或资源有没有**可执行的索取权**。

## 2. 代币的功能与价值捕获

| 功能 | 机制 | 价值捕获方式 | 例子 |
|---|---|---|---|
| 支付 / 计价 | 作为服务费或结算单位 | 需求增长 → 代币需求 | ETH 付 gas |
| 治理 | 投票、提案、参数调整 | 治理权本身有期权价值 | UNI、ARB |
| 现金流权 | 费用分红、回购销毁、费用开关 | 直接分配协议收入 | CRV（veCRV  boosts）、UNI 费用开关讨论 |
| 工作 / 质押凭证 | 验证者、保险、预言机抵押 | 质押需求 + 罚没风险 | ETH 质押、LINK |
| 准入权 | 会员、API 配额、白名单 | 稀缺准入的租金 | 部分 DePIN、RWA |

**价值捕获的四个问题**：

1. 协议收入流向谁？金库、LP、还是代币持有人？
2. 代币持有人能否** enforceable** 地索取？代码里有没有费用开关/回购？
3. 代币是**生产性资产**还是**消费性凭证**？
4. 如果协议成功，代币供应会不会被稀释到持有人拿不到多少？

监管上，代币可能被认定为证券（Howey 测试）、商品、支付工具或 utility token。MiCA 区分 utility token、ART、EMT；美国 SEC 的立场随执法与立法变化。设计代币时，**价值捕获机制与合规结构必须一起考虑**。

## 3. 估值框架

### 3.1 DCF：把协议收入折现

若协议把比例 $\beta$ 的收入分配给代币持有人（回购、分红、费用开关），则

$$
V=\sum_{t=1}^{T}\frac{FCF_t}{(1+r)^t}+\frac{TV}{(1+r)^T},
\qquad
TV=\frac{FCF_{T+1}}{r-g}
$$

其中 $FCF_t=\beta\cdot R_t$，$r$ 是折现率，$g$ 是终值增长率。

**手算**：协议第 1 年收入 \$60M，未来 5 年增长 25%，$\beta=50\%$，$r=12\%$，$g=3\%$。FCF 为 30、37.5、46.9、58.6、73.2（百万美元）。5 年现值约 \$168.8M；终值 $=73.2\times1.03/(0.12-0.03)=838.2$，折现后 \$475.6M；合计约 **\$644.5M**。按总供给 1B 枚，每枚 **\$0.64**。

DCF 的陷阱：代币不是股票，收入可能留在金库、被治理代币稀释、或根本没有费用开关；终值假设往往决定大部分估值。

### 3.2 货币流通速度模型

由 $MV=PQ$：

$$
M=\frac{PQ}{V},\qquad
\text{代币价格}=\frac{M}{\text{流通供给}}
$$

**手算**：某网络年经济量 $PQ=\$5B$，$V=4$，则 $M=\$1.25B$；按 1B 枚供给，每枚 **\$1.25**。

缺陷：$V$ 不是常数；$PQ$ 可能是刷量或重复计算；代币被质押/囤积时 $V$ 下降；代币价格还受治理、抵押与投机需求影响。它适合做**数量级 sanity check**，不适合当估值定理。

### 3.3 Metcalfe 与相对估值

Metcalfe 定律：网络价值 $\propto n^2$。用户从 10 万到 20 万，价值理论上 4 倍。它只能解释**相对变化**，不能给出绝对价格，且对“活跃用户”的定义与女巫账户极其敏感。

相对估值：

$$
P/S=\frac{\text{市值}}{\text{年收入}},\qquad
P/F=\frac{\text{市值}}{\text{年费用或回购}}
$$

对协议而言，P/F 比 P/S 更接近“股东现金流”，但要注意：交易费可能大部分给 LP，不是协议收入；排放和补贴会虚增使用量；不同协议的会计口径不同。

### 3.4 三种方法放在一起

以上例：DCF 给 \$0.64，流通速度给 \$1.25，市场价格 \$2.00。差异不是“谁算错了”，而是**假设不同**：

- DCF 假设 50% 收入永久分配给持币人；
- 流通速度假设代币是唯一的交易媒介且 $V=4$；
- 市场价包含治理、质押、叙事与流动性溢价。

> 好的估值不是给一个精确数字，而是给出**价格隐含的假设**：当前 \$2 对应多少收入增长、多少分配比例、多少折现率？

## 4. 供给设计

### 4.1 通胀与释放

若年通胀率为 $i$，供给 $S_t=S_0(1+i)^t$。若质押率为 $s$，且新币全部给质押者，则质押者的代币数量增长约 $i/s$，非质押者被稀释 $1/(1+i)$。**名义质押收益高不代表真实收益高**：若通胀 20%、质押率 50%，质押者的币量增长约 40%，但每枚币的购买力可能被稀释。

释放计划常用：

- **Cliff**：前 12 个月锁定，之后线性释放；
- **线性释放**：每月解锁固定比例；
- **里程碑释放**：按 TVL/收入达成解锁。

**手算**：总供给 1B，初始流通 200M（20%）；第 1 年毛解锁 125M，回购销毁 15M，年末流通 310M，净通胀

$$
\frac{310-200}{200}=55\%
$$

第 2 年再解锁 250M、销毁 18.8M，流通 541.3M，净通胀 74.6%。**低流通高 FDV** 的本质是：早期市值小，但解锁会持续稀释；FDV 与市值的缺口就是未来的供给悬顶。

### 4.2 回购与销毁

回购销毁：协议用收入在二级市场买入代币并销毁。若回购金额为 $B$、价格为 $P$，销毁量 $\Delta S=B/P$；销毁收益率近似 $B/\text{市值}$。

**手算**：第 1 年回购 \$30M，价格 \$2，销毁 15M 枚（总供给的 1.5%）；若价格 \$4，只销毁 7.5M 枚。**价格越低，同样预算销毁越多**——但市值也更低，不能只看销毁量。

回购 ≠ 必然上涨：它减少供给，但需求可能同时下降；若回购资金来自增发或借贷，效果更弱。回购与分红的区别在税务与会计，不在经济实质：都是把现金返还给持币人。

### 4.3 ve 模型

Curve 的 vote-escrow：

$$
ve = \text{amount}\times\frac{t_{\text{remaining}}}{T_{\max}}
$$

锁仓最长 4 年，投票权线性衰减；锁得越久，投票权与流动性挖矿 boost 越高。它把治理权与长期利益绑定，减少 mercenary 行为。代价：

- 代币流动性丧失，机会成本高；
- 治理权向大户与协议（Convex）集中；
- 出现“贿赂市场”（bribes），治理权被明码标价；
- ve 头寸不可转让（或通过 NFT 二级市场变相转让）。

ve(3,3)、veNFT 等变体试图解决流动性问题，但引入了新的复杂度。

## 5. 激励设计与筹资演进

### 5.1 流动性挖矿与“雇佣资本”

流动性挖矿：按 LP 份额发放代币。排放 APR 近似

$$
\text{APR}_{\text{emit}}=\frac{\text{年排放价值}}{\text{TVL}}
$$

资本会比较“排放 APR + 手续费收益率”与外部收益率。若排放停止，只追逐补贴的资本会离开，TVL 骤降——这就是**雇佣资本（mercenary capital）**。

**手算**：年排放 12M 枚、价格 \$0.5，排放预算 \$6M；手续费收益率 2%，外部收益率 5% + 风险溢价 1% = 6%，则排放需提供 4%，目标 TVL $=6M/0.04=\$150M$。若只有 37.5% 的 TVL 在补贴停止后留下，留存 \$56.25M；每 \$1 留存 TVL 的成本 $=6/56.25=\$0.107$。而按峰值 TVL 算的“朴素成本”只有 $6/150=\$0.04$——**真实成本被低估约 2.7 倍**。Lab 8.2 按价格下跌路径计算排放价值（\$4.50M）与峰值 TVL（\$129.73M），得到 \$0.092 与同样的 2.7×；绝对数不同，倍数一致。

缓解：ve 锁仓、把排放与实际使用量绑定、协议自有流动性（POL）、用真实费用而非增发支付、设置退出成本与反女巫规则。核心是让流动性留下是因为**产品有用**，而不是补贴最高。

### 5.2 积分、空投与女巫

- **积分**：链下记账，按交互、TVL、持有时间等给分；灵活但可被刷量，规则不透明会伤害社区。
- **空投**：按历史快照发放代币；常见资格包括交互次数、TVL、治理参与、NFT 持有。设计要考虑：sybil 聚类、 vesting、分层、可申诉。
- **女巫攻击**：一个人控制大量地址以放大空投。防御：地址聚类、资金流分析、社交验证、最低交互门槛、按“人”而非“地址”分配。

空投不是“免费获客”：它带来卖压、税务与法律风险、以及“撸完就走”的用户。好的空投应奖励**真实留存行为**，而不是一次交互。

### 5.3 筹资方式演进

| 阶段 | 机制 | 优点 | 问题 | 代表 |
|---|---|---|---|---|
| ICO（2017） | 公开众筹，ERC-20 直接卖 | 无许可、全球 | 诈骗、证券合规、破发 | 大量 2017 项目 |
| IEO（2019） | 交易所背书发行 | 尽调、流动性 | 中心化、交易所权力 | Binance Launchpad |
| 空投/积分（2020–） | 按使用行为发放 | 获客、去中心化 | 女巫、卖压、规则博弈 | Uniswap、Arbitrum、Blast |
| 再质押（2024–） | 用已质押资产为 AVS 提供安全 | 资本复用、收益叠加 | 杠杆化、系统性风险、罚没 | EigenLayer |

**案例**：Uniswap 2020-09 向约 25 万个历史地址各发 400 UNI；按 launch 价约 \$2–3 计算价值约 \$800–1,200，2021 年峰值 \$44 时约 \$17,600。它成为“空投获客”的模板，也引发大量刷量。Curve 的 veCRV 与“Curve wars”展示了治理权的价值：协议们争夺 veCRV 投票权以引导流动性，Convex 通过聚合 veCRV 成为关键中间人。OlympusDAO 的“(3,3)”则展示了反射性 tokenomics 的风险：高 APY 依赖新资金与 bonding，价格下跌后螺旋。

## 6. 代码 / 实现

一个最小 ERC-20 + 线性 vesting + 回购销毁的骨架：

```solidity
contract Token is ERC20 {
    address public immutable treasury;
    constructor() ERC20("Example", "EX") { _mint(treasury, 1_000_000_000e18); }
    function mint(address to, uint256 amt) external onlyTreasury { _mint(to, amt); }
    function burn(uint256 amt) external { _burn(msg.sender, amt); }
}

contract Vesting {
    // 12 个月 cliff，之后 36 个月线性释放
    uint64 public immutable start;
    uint256 public immutable total;
    uint256 public claimed;
    function vested() public view returns (uint256) {
        if (block.timestamp < start + 365 days) return 0;
        uint256 elapsed = block.timestamp - (start + 365 days);
        return total * Math.min(elapsed, 3 * 365 days) / (3 * 365 days);
    }
    function release() external {
        uint256 amount = vested() - claimed;
        claimed += amount;
        token.transfer(beneficiary, amount);
    }
}
```

**工程要点**：

- 释放计划用**时间戳与整数**，不要用区块数（出块时间可变）；
- 空投用 **Merkle distributor**：链下生成叶子，链上只存根，领取时验证证明（节省 gas）；
- 回购销毁要有**治理与时间锁**，否则管理员可以随意增发/销毁；
- 链上指标（流通量、持币集中度、真实费用）是“可观测性”，不要只看官网 FDV；
- 代币合约的**权限**（mint、pause、blacklist）就是经济权力，必须在文档中披露。

## 9. 常见误区

1. **“低流通、高 FDV 只是估值方式。”** 它是供给悬顶：早期市值小，解锁会持续稀释，且早期买家可能成为退出流动性。
2. **“代币价格涨 = 协议成功。”** 价格受流动性、叙事与杠杆影响；协议成功要看真实收入、留存与单位经济。
3. **“APY 就是收益。”** 很多 APY 来自代币增发；真实收益 = 手续费收入 − 排放稀释 − IL/LVR。
4. **“销毁一定上涨。”** 销毁减少供给，但需求可能下降；回购的钱从哪来、是否可持续更重要。
5. **“空投是免费获客。”** 女巫、卖压、税务与法律风险、撸完就走，都是成本。
6. **“ve 锁仓解决雇佣资本。”** 它把雇佣资本变成治理资本，可能带来治理集中与贿赂市场。
