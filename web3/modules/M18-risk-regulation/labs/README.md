参数：固定种子 `180018`；500 个交易日；98% 正常收益 $N(0.05\%,1.5\%)$，2% 跳跃 $N(-4\%,4\%)$；组合 1,000 万美元。

预期输出（完整）：

```text
Lab 18.1 VaR、CVaR 与回测
固定种子 = 180018；样本 = 500 天；组合市值 = $10,000,000
日收益率：均值 0.068%，标准差 1.639%，最小 -8.72%，最大 7.21%

== 1. 两种方法的风险度量 ==
方法 | 95% VaR | 95% CVaR | 99% VaR | 99% CVaR
历史模拟 |   $281,402 |   $366,612 |   $400,752 |   $543,692
参数正态 |   $262,785 |   $331,280 |   $374,494 |   $430,041
历史 95%：最差 5% 边界日收益率 = -2.81%，尾部 25 天
历史 99%：最差 1% 边界日收益率 = -4.01%，尾部 5 天
CVaR 总是大于等于 VaR；正态 95% 下 CVaR/VaR ≈ 2.06 / 1.645 ≈ 1.25。
历史 99% 明显高于正态 99%，说明样本存在厚尾/跳跃，正态假设低估极端风险。

== 2. 回测：实际突破 VaR 的天数 ==
95% VaR 突破 24 天，预期 25.0 天（5%）
99% VaR 突破 4 天，预期 5.0 天（1%）
突破天数接近预期说明模型校准尚可；若远多于预期，说明尾部被低估。
注意：VaR 回测通过不代表模型正确，只代表该分位数没有被系统性突破。

== 3. 压力测试：确定性冲击 ==
情景 | 组合损失 | 相对 95% VaR 的倍数
 -10% |   $1,000,000 | 3.6×
 -20% |   $2,000,000 | 7.1×
 -30% |   $3,000,000 | 10.7×
若波动率翻倍，参数法 99% VaR = $755,826（原 $374,494）
压力测试回答“如果发生某个坏情景会亏多少”，不依赖历史分布的分位数。

== 4. 次可加性：VaR 可能惩罚分散化 ==
组合 | 95% VaR | 95% CVaR
A    |       0 |    80.00
B    |       0 |    80.00
A+B  |     100 |   100.00
VaR(A) + VaR(B) = 0，VaR(A+B) = 100
VaR(A+B) > VaR(A)+VaR(B)，违反次可加性：合并两个“平时都安全”的尾部风险反而更危险。
CVaR(A)+CVaR(B) = 160，CVaR(A+B) = 100：满足次可加性。

== 5. 结论与思考 ==
1. VaR 是分位数，不告诉你尾部有多厚；CVaR 是尾部条件均值，更适合描述极端损失。
2. 历史模拟保留厚尾与跳跃，但依赖样本；参数正态法光滑、可解析，但低估尾部。
3. 回测只能检验分位数，不能检验整个分布；必须配合压力测试与情景分析。
4. VaR 不满足次可加性，不能简单把各业务线 VaR 相加得到总 VaR。
动手改一改：把跳跃概率从 2% 改成 8%，观察历史 99% VaR 与正态 99% VaR 的差距。
```

## Lab 18.2 借贷池 Agent-Based 压力测试

```bash
node modules/M18-risk-regulation/labs/02-lending-abm.mjs
```

| 文件 | 内容 |
|---|---|
| `02-lending-abm.mjs` | 120 个借款人、清算人、套利者；5 种价格路径；预言机延迟、清算资金约束、清算瀑布与坏账 |

参数：固定种子 `180032`；120 个借款人，抵押 5–25 ETH，初始 LTV 35%–70%；清算阈值 80%、罚金 8%、close factor 50%；DEX 初始 5,000 ETH / 1,500 万 USDC、费率 0.3%；套利者 1,000 ETH 库存；40% 借款人在 HF<1.15 时主动还 10% 债务。

预期输出（完整）：

```text

== 2. 模拟结果 vs 静态解析基准 ==
情景 | 真实终价 | 已实现+潜在坏账 | 静态基准 | 差异 | 占初始存款

静态基准假设所有头寸在最终价格一次性全额清算；它忽略了路径、close factor、滑点与资金约束。
延迟场景的已实现坏账可能更低，但潜在坏账更高：风险只是被推迟，并没有消失。
```
