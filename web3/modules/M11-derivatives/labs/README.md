## Lab 11.1 永续资金费率与 Delta 中性回测

```bash
node modules/M11-derivatives/labs/01-funding-delta-neutral.mjs
```

| 文件 | 内容 |
|---|---|
| `01-funding-delta-neutral.mjs` | 90 天价格路径、资金费公式、Delta 中性收益分解、负溢价情景、杠杆与清算表 |

实验参数：90 天，每 8 小时结算一次，共 270 期；现货多 5 ETH + 永续空 5 ETH；初始资本 \$20,000（现货 \$10,000 + 保证金 \$10,000）；现货手续费 0.1%/边，永续 0.05%/边；维持保证金 5%；每期利率项 0.01%，溢价钳制 ±0.05%。

预期输出（节选，数字应与实际运行一致）：

```
--- 2. 收益分解（90 天）---
期末价格: $3,000.00
现货盈亏: $5,000.00
永续盈亏: $-5,000.00
价格方向净盈亏: $0.00（理论上应为 0）
累计资金费收入: $697.29
手续费合计: $37.50（现货双边 + 永续双边）
策略净盈亏: $674.79
期末权益: $20,674.79，90 天收益率 3.37%，年化 14.41%
最大回撤: 0.07%，最低保证金率: 37.9%

--- 3. “平均资金费率”与“实际策略收益”的差异 ---
平均每期资金费率: 0.0226% → 简单年化 24.79%（按名义价值）
实际资金费收入 / 初始资本，年化: 14.14%
策略实际年化收益（扣手续费）: 14.41%
```

```
--- 5. 风险情景：资金费率转负 ---
负溢价情景平均每期资金费率: -0.0029% → 简单年化 -3.23%
累计资金费: $-99.92，策略净盈亏: $-122.42，年化 -2.46%
最低保证金率: 32.6%
```

**检查点**

1. 现货与永续的价格盈亏完全抵消（+\$5,000 与 -\$5,000），期末权益只来自资金费减手续费。
2. 资金费 \$697.29 是按每期“5 ETH × 当期价格”累计的，不是简单用初始名义价值 \$10,000 乘以平均费率。
3. “平均费率年化 24.79%”是按名义价值，策略实际年化 14.41% 是按 \$20,000 资本；资本约是名义的 2 倍，所以收益率约减半，再扣手续费。
4. 负溢价情景下策略持续失血：资金费 -\$99.92，净亏 \$122.42，年化 -2.46%。Delta 中性不是无风险。
5. 保证金从 \$10,000 降到 \$5,000 时，理论清算价 \$2,857.14，路径最高价 \$3,000 会触发清算；最低保证金率降到 4.6%。杠杆放大收益，也放大清算概率。

**任务**

1. 把 `CLAMP` 从 0.05% 改为 0.02%，重跑实验。记录平均资金费、累计资金费、策略年化和最低保证金率的变化。
2. 把 `buildPath(0)` 的参数改为 `-0.0010`，重跑实验。解释为什么负溢价时“空头收取资金费”的直觉不成立。
3. 把 `MARGIN` 从 10,000 改为 5,000，保持 `QTY=5`。杠杆变成多少？最低保证金率和清算价如何变化？
4. 把 `INTEREST` 从 0.0001 改为 0.0003，观察资金费率路径。利率项在公式中起什么作用？为什么它被 clamp 限制？

## Lab 11.2 Black–Scholes、Greeks 与隐含波动率

```bash
node modules/M11-derivatives/labs/02-black-scholes-greeks.mjs
```

| 文件 | 内容 |
|---|---|
| `02-black-scholes-greeks.mjs` | BS 定价、看跌看涨平价、解析 Greeks vs 中心差分、隐含波动率二分、波动率微笑、蒙特卡洛 |

实验参数：$S=2000$，$K=2000$，$r=5\%$，$\sigma=60\%$，$T=0.25$ 年；蒙特卡洛 200,000 条路径，固定种子 `20261103`。

预期输出（节选）：

```

d1 = 0.191667, d2 = -0.108333
N(d1) = 0.575998, N(d2) = 0.456866
看涨期权 C = 249.62
看跌期权 P = 224.77
看跌看涨平价: C - P = 24.844399，S - K·e^(-rT) = 24.844399
平价误差 = 0.0000000000

--- 2. Greeks：解析公式 vs 中心差分 ---
Delta              0.575998      0.575998  0.0000004083
Gamma              0.000653      0.000653  0.0000000274
Vega(每 1% σ)       3.916814      3.916806  0.0000073000
Theta(每日)         -1.411333     -1.411351  0.0000173896
Rho(每 1% r)        2.255952      2.255950  0.0000015945

--- 5. 蒙特卡洛校验（固定种子 20261103，200,000 条路径）---
解析解 C = $249.6160
蒙特卡洛 C = $249.8305
标准误 = $0.9545，95% 置信区间 = [$247.960, $251.701]
偏差 = $0.2145（约 0.22 个标准误）
```

**检查点**

1. $d_1=0.191667$、$d_2=-0.108333$，$N(d_1)=0.575998$、$N(d_2)=0.456866$；$C=249.62$、$P=224.77$。
2. 平价 $C-P=24.844399$ 与 $S-Ke^{-rT}=24.844399$ 完全一致，误差为 0。
3. Greeks 的解析值与中心差分值在小数点后 5–6 位一致；Delta 约 0.576，Gamma 约 0.000653，Vega 每 1% 约 \$3.92，Theta 每日约 -\$1.41，Rho 每 1% 约 \$2.26。
4. 市场价 \$250 反解 IV 为 60.0980%，回代价格 \$250.000000；IV 是 BS 中唯一不可直接观测的输入。
5. 蒙特卡洛 200,000 条路径得到 \$249.8305，与解析解 \$249.6160 差 \$0.2145，约 0.22 个标准误；95% 置信区间包含解析解。
6. 持有到期、标的 \$2,400 时看涨期权内在价值 \$400，扣权利金后净赚 \$150.38；标的 \$1,800 时期权作废，买方损失全部权利金 \$249.62。

**任务**

1. 把 $T$ 从 0.25 改成 1，记录 $C$、$P$、Vega、Theta 的变化。为什么长期期权对波动率更敏感、每日时间损耗更小？
2. 把市场看涨价格改成 \$300，用二分法反解 IV。它与 60% 相差多少？
3. 把 $K$ 改成 1800、2200，观察 IV 微笑。为什么真实市场的深度虚值 put 通常 IV 更高？
4. 把蒙特卡洛路径数从 200,000 改成 20,000、2,000,000，记录标准误和运行时间。验证标准误按 $O(1/\sqrt N)$ 缩小。

## 常见问题

- **为什么资金费不是交易所收的？** 资金费是多空之间的转移支付；交易所在公式中可能抽取一部分，但经济本质是锚定永续价格的机制。正费率时多头付给空头，负费率时反过来。
- **为什么 Delta 中性还会有回撤？** 现货与永续的价格不完全同步（基差）、手续费、资金费转负、保证金不足被清算、交易所托管风险都会造成回撤。
- **为什么 BS 的价格与市场价格不同？** BS 是假设模型；市场价格包含供需、流动性、尾部风险和波动率曲面。交易的是 IV，不是单一 σ。
- **为什么蒙特卡洛要用固定种子？** 为了可复现教学结果；真实定价会用大量路径和方差缩减，并报告置信区间。
