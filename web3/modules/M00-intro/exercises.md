## 参考答案

**A1**　Web1：只读，如门户网站 / 雅虎；Web2：读写，用户生成内容但平台拥有数据，如微信、抖音；Web3：读写 + 拥有，资产由用户私钥控制，如以太坊上的 ERC-20 代币与钱包。

**A2**　双花是同一份数字资产被花两次。签名只能证明"消息出自某人"，不能证明"此人没签过另一条冲突的消息"——两条冲突交易都可以有合法签名。解决方法是让全网对交易**顺序**达成共识，只承认先者。

**A3**　逻辑上是中心化的：全网只认一本账、一个状态。正因为只有"一本账"，才可能防止双花、才能让任意合约相互组合；而架构与政治上的去中心化则保证这本账不被单一主体控制。

**A4**　① 私钥被盗：法律上你仍是所有者，但资产已被转走，追回需要依赖交易所冻结或司法协助；② 交易所托管：你拥有对交易所的债权（法律所有权），私钥在交易所手里——交易所破产时（如 FTX）你成为普通债权人；另有：继承时继承人有法律权利却无私钥，资产实际永久丢失。

**A5**　积分系统参与方信任同一运营者（奶茶店），验证成本本来就低，上链只增加冗余计算成本与复杂度，$C_{\text{链上}} > C_{\text{中介}}$。跨境汇款涉及多家代理行、外汇管制与较高抽成，中介成本高、到账慢，链上稳定币显著降低验证与结算成本，因此 $C_{\text{链上}} < C_{\text{中介}}$ 的区间真实存在（同时须遵守各地外汇与反洗钱法规）。

**B1**
1. 累加：25 → 43 > 33.3，故 $N = 2$。
2. 25 + 18 + 14 = 57 > 50，而 25 + 18 = 43 < 50，故 $N = 3$。
3. $\text{HHI} = 25^2 + 18^2 + 14^2 + 12^2 + 10^2 + 9^2 + 7^2 + 5^2 = 625 + 324 + 196 + 144 + 100 + 81 + 49 + 25 = 1544$，属于中度集中（1000–1800）。

**B2**
1. $\min(\text{maxFee},\ \text{baseFee} + \text{maxPriority}) = \min(30,\ 12+2) = 14$ gwei。
2. 总费 $= 52000 \times 14 = 728000$ gwei $= 0.000728$ ETH；销毁 $52000 \times 12 = 624000$ gwei $= 0.000624$ ETH；小费 $52000 \times 2 = 104000$ gwei $= 0.000104$ ETH。
3. $\min(30,\ 29+2) = 30$ gwei，小费被压缩到 $30 - 29 = 1$ gwei。

**B3**　中介成本 $C_m = 0.02x + 5$，链上 $C_c = 0.001x + 0.5$。$C_c < C_m \iff 0.019x + 4.5 > 0 $，对所有 $x>0$ 恒成立——在此参数下链上始终更便宜。启示：若再考虑出入金渠道的合规成本、价格波动或更高点差（例如 $3\%$），结论可能翻转：令 $0.03x + 0.5 < 0.02x + 5 \Rightarrow x < 450$，即只在小额时更便宜。参数假设决定结论，这正是要做敏感性分析的原因。

**C2 提示**　`Number(receipt.gasUsed) / Number(block.gasUsed) * 100`。

**C3 提示**　循环 `getBlock({ blockNumber: latest - i, includeTransactions: true })`，按 `tx.type` 计数。eip4844（blob）交易主要由 L2 排序器 / 批次提交者发出，用来把 L2 交易数据发布到 L1（M13 详述）。
