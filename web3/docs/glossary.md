# 术语表（Glossary）

> 按主题分组，括号内为主要相关模块。遇到陌生缩写时先查这里。

## 密码学与数据结构

| 术语 | 含义 |
|---|---|
| 哈希函数（M1） | 任意长输入 → 固定长输出的公开函数；核心性质：抗原像、抗第二原像、抗碰撞。 |
| 抗原像 / 单向性（M1） | 给定 `y`，难以找到 `x` 使 `H(x)=y`；通用代价 `2^n`。 |
| 抗第二原像（M1） | 给定 `x`，难以找到 `x'≠x` 且 `H(x')=H(x)`；通用代价 `2^n`。 |
| 抗碰撞（M1） | 难以找到任意一对 `x≠x'` 且 `H(x)=H(x')`；生日界 `2^{n/2}`。 |
| Merkle 树（M1） | 把数据块哈希为叶子、两两向上合并为根的树；包含证明大小 `O(log N)`。 |
| Merkle Patricia Trie（M4） | 以太坊用于状态、交易、收据的键值 Merkle 结构，支持按地址查找与更新。 |
| 承诺方案（M1） | 先锁值、后揭示；隐藏性 + 绑定性；如 `H(v‖r)`、Pedersen、KZG。 |
| ECDSA（M1） | 椭圆曲线签名；以太坊交易签名；签名可延展性由 EIP-2 的 low-s 规则约束。 |
| Schnorr / BLS（M1、M3） | 两种签名方案；BLS 支持非交互聚合，用于以太坊共识层。 |
| 域分离（M1） | 给不同用途的哈希输入加不同前缀，避免结构混用（如 Merkle 叶子 `0x00`、内部节点 `0x01`）。 |
| 随机预言机模型（M1） | 把哈希理想化为随机函数，用于分析通用攻击代价。 |
| 生日界（M1） | `q ≈ 1.177√N` 时碰撞概率约 50%；`N=2^n` 时约 `2^{n/2}`。 |

## 共识与分布式系统

| 术语 | 含义 |
|---|---|
| 拜占庭故障（M2） | 节点可能任意作恶（不发消息、发矛盾消息），不只是崩溃。 |
| FLP 不可能性（M2） | 完全异步网络中，即使只有一个崩溃节点，也不存在同时保证安全性与活性的确定性共识。 |
| CAP（M2） | 一致性、可用性、分区容忍三者不可同时满足；区块链通常优先一致性与分区容忍，牺牲即时可用性。 |
| PBFT / HotStuff / Tendermint（M2） | 经典 BFT 共识；通常要求 `n ≥ 3f+1` 才能容忍 `f` 个拜占庭节点。 |
| 中本聪共识（M2） | PoW + 最长（最重）链 + 概率最终性；无需许可参与。 |
| Gasper（M2） | 以太坊 PoS 的 Casper FFG（最终性）+ LMD-GHOST（分叉选择）组合。 |
| 罚没（slashing，M2） | PoS 中惩罚违反协议的验证者，部分质押被销毁。 |
| 无利害关系问题（M2） | PoS 验证者在分叉上同时投票几乎没有边际成本；用罚没与弱主观性缓解。 |
| 弱主观性（M2） | 新节点需要最近的可信检查点才能安全同步，而非仅靠创世块。 |
| 数据可用性（M2、M13） | 区块数据必须可被验证者获取，否则无法发现隐藏的无效区块。 |
| 最终性（M2） | 交易被逆转的概率可忽略；PoW 是概率最终性，BFT/PoS 有经济最终性。 |

## 比特币与以太坊

| 术语 | 含义 |
|---|---|
| UTXO（M3） | 未花费交易输出；比特币用"硬币"集合而非账户余额建模。 |
| Bitcoin Script（M3） | 基于栈的锁定/解锁脚本；P2PKH、P2SH、多签、CLTV/CSV。 |
| SegWit / Taproot（M3） | 隔离见证与 Schnorr+MAST 升级；提高容量、隐私与脚本灵活性。 |
| 减半（M3） | 比特币每 210,000 个块把区块补贴减半；总供给约 2100 万 BTC。 |
| 闪电网络 / HTLC（M3） | 链下支付通道网络；哈希时间锁合约保证原子路由。 |
| EOA / 合约账户（M4） | 以太坊两类账户；EOA 由私钥控制，合约由代码控制。 |
| EVM（M4） | 以太坊虚拟机；栈式、256 位字长、按 gas 计费。 |
| Gas / baseFee / priorityFee（M4） | 执行资源计量；EIP-1559 把费用拆为基础费（销毁）与小费（给验证者）。 |
| Blob（EIP-4844，M4、M13） | 为 L2 数据可用性设计的低成本数据块，不进入 EVM 执行。 |
| MPT / Verkle（M4） | 以太坊状态树；Verkle 用于缩小见证大小。 |
| PBS / MEV-Boost（M4、M12） | 提议者-构建者分离；区块构建外包给专业构建者。 |
| 代理模式（M5） | 通过 `delegatecall` 让逻辑合约在代理存储上执行；UUPS/Transparent/Beacon。 |
| ABI / 函数选择器（M5） | 合约调用编码；选择器是签名 Keccak-256 的前 4 字节。 |
| ERC-20 / 721 / 1155 / 4626（M5） | 同质化代币、NFT、多代币、收益金库标准。 |
| EIP-712（M5、M15） | 结构化类型数据签名；钱包可读、防重放。 |

## 金融与应用

| 术语 | 含义 |
|---|---|
| 稳定币（M7） | 目标锚定法币的加密资产；法币抵押、加密超额抵押、合成、算法等类型。 |
| CDP（M7、M10） | 抵押债务头寸；锁定抵押品、铸造稳定币、维持抵押率。 |
| 抵押率 / 清算阈值（M7、M10） | 抵押品价值 / 债务；低于阈值触发清算。 |
| 死亡螺旋（M7） | 价格下跌 → 清算/赎回 → 进一步下跌的正反馈。 |
| TVL（M8、M17） | 锁仓总价值；易被重复计算与价格波动扭曲。 |
| FDV / 流通市值（M8） | 完全稀释估值 / 当前流通量 × 价格。 |
| ve 模型（M8） | 锁仓换取治理权与收益；如 veCRV。 |
| AMM（M9） | 自动做市商；用数学公式代替订单簿。 |
| 恒定乘积（M9） | `x·y=k`；Uniswap v2 的核心不变量。 |
| 集中流动性（M9） | Uniswap v3 在价格区间内提供流动性，提高资本效率。 |
| 无常损失（M9） | LP 相对单纯持有资产的损失；`IL(r)=2√r/(1+r)-1`。 |
| LVR（M9） | Loss-versus-Rebalancing；LP 因套利者逆向选择而损失的更准确度量。 |
| 利用率（M10） | 借款 / 存款；驱动利率模型。 |
| 健康因子（M10） | 抵押品价值 × 清算阈值 / 债务；`HF<1` 可清算。 |
| 闪电贷（M10） | 同一交易内借入并归还，无需抵押；常用于套利与攻击。 |
| 永续合约（M11） | 无到期日的衍生品；用资金费率锚定现货。 |
| 资金费率（M11） | 多空之间定期支付，压缩永续价格与现货的偏差。 |
| LST / LRT（M11） | 流动性质押代币 / 再质押代币；收益叠加也带来风险叠加。 |
| MEV（M12） | 最大可提取价值；通过排序、插入、审查交易获得的利润。 |
| 三明治攻击（M12） | 前置买入 + 受害者交易 + 后置卖出，赚取受害者滑点。 |
| 预言机（M12） | 把链外价格/数据引入链上；Chainlink、Pyth、TWAP。 |
| TWAP（M12） | 时间加权平均价格；操纵成本随窗口与流动性上升。 |

## 扩容、隐私与账户

| 术语 | 含义 |
|---|---|
| Rollup（M13） | 在 L2 执行、把数据/证明提交到 L1 的扩容方案。 |
| Optimistic Rollup（M13） | 默认乐观，挑战期内可提交欺诈证明；最终性延迟。 |
| ZK Rollup（M13） | 用有效性证明保证状态转换正确；最终性更快但证明成本高。 |
| zkEVM Type 1–4（M13） | 与以太坊 EVM 兼容程度不同的 ZK 方案谱系。 |
| DAS / PeerDAS（M13） | 数据可用性采样；轻客户端抽样验证数据可用。 |
| 排序器（M13） | L2 中负责排序与打包交易的实体；中心化排序器是常见风险。 |
| SNARK / STARK（M14） | 零知识证明的两大类别；SNARK 证明小、常需可信设置，STARK 透明但证明大。 |
| R1CS / QAP（M14） | 把计算写成约束系统，再转成多项式等式。 |
| KZG / FRI（M14） | 多项式承诺方案；KZG 需可信设置，FRI 透明。 |
| Schwartz–Zippel（M14） | 低阶多项式在随机点上为零的概率 ≤ `d/|F|`。 |
| ERC-4337（M15） | 账户抽象：UserOperation、Bundler、Paymaster、EntryPoint。 |
| EIP-7702（M15） | 让 EOA 临时委托代码，获得智能账户能力。 |
| 社交恢复 / 会话密钥（M15） | 智能钱包的恢复与受限授权机制。 |
| 跨链桥（M15） | 锁定铸造、流动性网络、轻客户端/ZK 桥；信任模型差异巨大。 |

## 数据与风险

| 术语 | 含义 |
|---|---|
| HHI（M0、M17） | 赫芬达尔-赫希曼指数；份额平方和，衡量集中度。 |
| Gini（M17） | 基尼系数；衡量持币/收入分布不平等。 |
| 地址聚类（M17） | 用交易图启发式把多个地址归为同一实体。 |
| 事件研究 / DID（M17） | 因果推断方法；DID 用处理组与对照组的双重差分。 |
| VaR / CVaR（M18） | 在给定置信水平下的最大损失 / 超过 VaR 的条件期望损失。 |
| Agent-Based 模拟（M18） | 用多类代理的行为规则模拟系统压力。 |
| Howey 测试（M18） | 美国判断投资合同是否构成证券的四要素测试。 |
| MiCA（M7、M18） | 欧盟加密资产市场监管框架。 |
| FATF 旅行规则（M18） | 虚拟资产服务商需传递交易双方信息的反洗钱要求。 |
