## 2. 风险分类与检查表

### 2.1 合约风险

- [ ] 是否可升级？升级权限在谁手里？有无时间锁？
- [ ] 重入、访问控制、整数、签名重放、初始化；
- [ ] 外部调用（ERC-777 / 原生转账 / 回调）是否遵循 CEI？
- [ ] 预言机失败时是否有降级 / 暂停？
- [ ] 是否依赖 `tx.origin`、`block.timestamp`、`blockhash` 等易变值？
- [ ] 审计范围是否覆盖当前 commit？审计后是否改过代码？

### 2.2 经济设计风险

- [ ] 抵押品与债务的相关性（是否会在同一冲击下同时恶化）？
- [ ] 清算激励是否足够？清算人会不会在极端行情下缺席？
- [ ] 利率模型在利用率 100% 时是否还有借款需求？
- [ ] 稳定币 / LST 的脱锚如何传导？
- [ ] 激励补贴停止后，TVL 与利率会怎样变化？
- [ ] 是否存在"收益来自新进资金"的庞氏结构？

### 2.3 预言机风险

- [ ] 价格来源：Chainlink / Pyth / TWAP / 自建；
- [ ] 更新频率、心跳、偏差阈值；
- [ ] 操纵成本：现货流动性 × 时间窗口；
- [ ] 单一来源失效 / 多源分歧时的处理；
- [ ] 极端行情下的清算级联。

### 2.4 治理风险

- [ ] 提案门槛、投票期、执行延迟；
- [ ] 投票权集中度（HHI / Nakamoto 系数）；
- [ ] 借币投票、闪电贷投票、贿赂；
- [ ] 多签成员、地理与法律分散度；
- [ ] 紧急暂停权是否可被滥用？

### 2.5 托管 / 密钥风险

- [ ] 管理员密钥类型（EOA / 多签 / MPC / HSK）；
- [ ] 私钥生成、备份、轮换、离职流程；
- [ ] 前端供应链、DNS、域名、依赖包；
- [ ] 运营安全（钓鱼、社交工程）。

### 2.6 流动性风险

- [ ] 主要交易场所的深度与滑点；
- [ ] 大额赎回 / 清算时的市场冲击；
- [ ] 借贷池的流动性错配（短借长贷）；
- [ ] 跨链桥的锁定资产与流动性。

### 2.7 监管 / 合规风险

- [ ] 代币是否可能被认定为证券（Howey）？
- [ ] 是否涉及稳定币、衍生品、托管、汇款牌照？
- [ ] KYC / AML / 制裁筛查；
- [ ] 地区限制（中国大陆禁止相关业务活动）；
- [ ] 法律实体与用户条款。

## 4. 量化工具

### 4.1 VaR / CVaR

- 置信水平（95% / 99%）、时间窗口（1 天 / 10 天）；
- 方法：历史模拟 / 参数法 / 蒙特卡洛；
- 数据来源与样本期；
- 结果：`VaR_95`、`CVaR_95`，并说明局限（尾部、相关性、流动性）。

### 4.2 压力测试

- 价格冲击、波动率飙升、流动性枯竭、预言机延迟；
- 输出：坏账、清算缺口、池子利用率、金库剩余。

### 4.3 Agent-Based 模拟

- 代理类型：借款人、清算人、套利者、恐慌存款人；
- 行为规则与参数；
- 输出分布，而不是单点结果；
- 用 M18 的 lab 做基线，再替换参数。
