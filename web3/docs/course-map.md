# 课程地图（一页版）

> 详细大纲见 [`SYLLABUS.md`](../SYLLABUS.md)，进度与链接见根目录 [`README.md`](../README.md)。

## 一条主线

**密码学 → 共识 → 账本 → 合约 → 金融 → 扩容 → 应用 → 数据与风险**

每一层回答一个问题：

| 层 | 问题 | 模块 |
|---|---|---|
| 密码学 | 这笔钱是谁的？这条消息是谁发的？ | M1 |
| 共识 | 大家凭什么认同同一本账？ | M2 |
| 账本 | 比特币如何用 UTXO 与 PoW 实现第一套系统？ | M3 |
| 执行 | 以太坊如何把账本变成状态机？ | M4 |
| 合约 | 如何写出正确、可升级、可组合的合约？ | M5 |
| 安全 | 合约会怎样被攻破？如何审计与运营？ | M6 |
| 货币 | 稳定币凭什么锚定一美元？ | M7 |
| 激励 | 代币如何协调供给、需求与治理？ | M8 |
| 交易 | AMM 如何定价？LP 的收益与损失从哪来？ | M9 |
| 信用 | 超额抵押借贷如何清算？坏账从哪来？ | M10 |
| 衍生品 | 永续、期权、质押收益如何定价与叠加风险？ | M11 |
| 微观结构 | 排序权值多少钱？预言机如何被操纵？ | M12 |
| 扩容 | 把执行搬到 L2，安全如何继承 L1？ | M13 |
| 隐私 | 如何证明“我知道”，但不告诉你“是什么”？ | M14 |
| 账户 | 钱包能否像 Web2 一样好用，同时保持自托管？ | M15 |
| 应用 | NFT、DAO、DID、RWA 的真实需求是什么？ | M16 |
| 数据 | 如何用链上数据做可复现的实证研究？ | M17 |
| 风险 | 如何识别、量化并监管系统性风险？ | M18 |
| 综合 | 把以上知识做成一个可演示、可审计的项目 | Capstone |

## 模块速查

| 模块 | 一句话 | 关键公式 / 工具 | 实验 |
|---|---|---|---|
| M0 | 从 Web1 到 Web3 的价值互联网 | Nakamoto 系数、HHI | 追踪交易 |
| M1 | 哈希、签名、Merkle、HD 钱包 | 生日界、ECDSA、BIP-32/39/44 | SHA-256 / Merkle / ECDSA |
| M2 | BFT、PoW、PoS 与博弈 | `n ≥ 3f+1`、Nakamoto 追上概率 | PoW 分叉模拟、双花 |
| M3 | UTXO、Script、SegWit/Taproot、闪电网络 | 减半供给、HTLC | UTXO / 脚本 / 供给曲线 |
| M4 | EVM、状态、gas、EIP-1559、blob | 基础费调整公式 | 基础费模拟、读取 Sepolia |
| M5 | Solidity、ABI、代理、代币标准 | 选择器、存储布局 | ABI/存储槽、ERC-20 状态机 |
| M6 | 重入、访问控制、重放、价格操纵 | CEI、审计流程 | 攻击-修复对照 |
| M7 | 稳定币机制、挤兑、监管 | 抵押率、`MV=PQ` | CDP 清算、死亡螺旋 |
| M8 | 代币功能、估值、供给与激励 | DCF、`PQ/V`、P/F | 释放模型、雇佣资本 |
| M9 | 恒定乘积、集中流动性、IL/LVR | `x·y=k`、`IL(r)` | 交换、IL、LVR |
| M10 | 资金池借贷、利率、清算、闪电贷 | 利用率、健康因子 | 清算与坏账、闪电贷 |
| M11 | 永续、期权、LST/LRT、收益分解 | 资金费率、Black–Scholes | Delta 中性、Greeks |
| M12 | MEV 供应链、三明治、预言机 | 三明治利润、TWAP | 最优前置、TWAP 操纵 |
| M13 | Optimistic/ZK Rollup、DA、排序器 | L2 收入 = 费用 − L1 成本 | 费用拆分、挑战期 |
| M14 | R1CS/QAP、KZG/FRI、SNARK/STARK | Schwartz–Zippel | Merkle + Fiat–Shamir |
| M15 | ERC-4337、7702、智能钱包、跨链桥 | UserOperation 生命周期 | 4337 流程、跨链重放 |
| M16 | NFT、DAO、DID、RWA | 二次方投票 / 资助 | 二次方投票、版税 |
| M17 | 数据层次、指标、聚类、因果推断 | HHI、Gini、DID | 集中度、事件索引器 |
| M18 | 风险分类、VaR/CVaR、压力测试、监管 | VaR、CVaR、Howey | VaR/CVaR、Agent 模拟 |

## 学习节奏建议

- **第 1–4 周**：M0–M3，打牢密码学、共识与比特币；每章至少跑一个实验。
- **第 5–8 周**：M4–M6，重点在合约工程与安全；M6 的审计报告模板要亲手填一次。
- **第 9–14 周**：M7–M12，金融模块可以按兴趣排序，但 M9 是 M10–M12 的前置。
- **第 15–17 周**：M13–M15，理解扩容、隐私与账户抽象。
- **第 18–19 周**：M16–M18，应用、数据与风险；开始 Capstone。
- **第 20 周+**：Capstone 交付与答辩。
